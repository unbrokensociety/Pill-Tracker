# 🚀 PillTracker v1.58 — Release Notes

### 🌟 What's New
* 💊 **Local Offline Medication Management**: Full offline pill tracker with exact time reminders (`AlarmManager.setAlarmClock`), Room database storage, and zero account registration requirement.
* 🎨 **Material 3 Custom Theme Selection**: Choose between System, Light, and Dark themes dynamically in Settings.
* 📜 **Fixed Edge-to-Edge Privacy Dialogs**: Privacy Policy & Terms of Service dialogs now render full screen edge-to-edge with clear consent action buttons.
* 🔑 **Guaranteed Update Compatibility**: Embedded `debug.keystore.base64` signature guarantees seamless APK updates without signature mismatch errors.
* ⏰ **Smart Alarm Cancellation**: Toggling notifications off properly cancels active system alarms to save device battery.
